# 🌟 Mandy Zhang — Personal Portfolio

This is my personal portfolio website built with **React**, showcasing my UI/UX work, professional experience, and full-stack projects.  
The site includes multi-company case studies, personal app demos, and a detailed overview of my skills and engineering approach.

🔗 **Live Portfolio:** https://looklook33.github.io/react-portfolio  
📌 Built with: React · JavaScript · HTML5 · CSS3 · GitHub Pages

## ✨ Features

- 🎨 Modern UI with smooth transitions & responsive layout  
- 🧭 Easy navigation between Home, About, Work, and Contact pages  
- 📁 Case Study pages (Snorkel AI, Wayfair, personal projects)
